# Raster releases

Raster is an IPTV player for **Fire TV** and **Android TV**. This repository only holds the
release builds. Raster checks it for updates by itself (Settings › Updates).

Raster plays your own provider's streams. It doesn't come with any channels or content.

## Install

1. Download the APK for your device from the [latest release](../../releases/latest).
   Most Fire TV devices need **`armeabi-v7a`**, even 64-bit ones.
2. On the Fire TV: *Settings › My Fire TV › Developer options* → allow apps from unknown sources
   (or allow the Downloader app), then open the APK.

Every APK is signed with Raster's release key, and GitHub publishes a SHA-256 checksum for each
file. Raster only installs an update whose checksum matches.

## Raster Premium

Raster is free. Premium unlocks recording, longer rewind, multiview, more than one provider, and themes and
Home layouts. It's a one-off purchase.

**Just bought it?** Your license key is in the email from Dodo Payments. On the TV, open
**Settings › Raster Premium › Enter License Key**, or scan the code there with your phone and paste the key.
To move Premium to another TV, choose **Remove from This TV** on the old one first.
